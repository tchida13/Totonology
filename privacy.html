Totonology

プライバシーポリシー・免責事項

制定: 2026年11月15日

Totonology（以下「本サイト」）は、サウナの楽しみ方から16タイプの性格を診断する、娯楽目的の無料サービスです。本ページでは、本サイトにおける情報の取り扱いと、ご利用上の注意をまとめています。

1. 運営者

本サイトは個人が運営しており、運営者の氏名・名称は公開していません。

2. 取得する情報と使い方

  • 診断の回答は、お使いのブラウザの中だけで処理されます。回答や診断結果を、運営者のサーバーへ送信・保存することはありません（本サイトにはアカウント登録も入力フォームもありません）。
  • 回答の途中経過は、ブラウザの sessionStorage に一時的に保存されます。タブを閉じると消え、運営者が読み取ることはできません。
  • 診断後のURLの # 以降には、結果の復元用に回答内容が含まれます。この部分はサーバーには送信されませんが、アドレスバーやリンクのコピー機能で取得したURLをそのまま他の人に渡すと、回答内容も共有されます。SNSなどでのシェアには、回答を含まない「タイプ別ページ」のURLが使われます。
  • 氏名・メールアドレス・位置情報など、個人を特定できる情報は取得しません。

3. Cookie・アクセス解析

本サイトは Cookie を使用しません。また、現時点ではアクセス解析ツールも導入していません。今後導入する場合は、計測する内容と使用するサービスを、導入前に本ページへ追記します。

4. 外部サービス

  • GitHub Pages: 本サイトは GitHub Pages で配信されています。サイトへのアクセス時に、GitHub 側でIPアドレスなどのアクセスログが取得される場合があります。詳しくは GitHub のプライバシーに関する声明をご確認ください。
  • X（旧Twitter）: 「結果をシェア」を押すと、X の投稿画面が開きます。投稿内容はご自身で確認のうえ、投稿してください。その後の取り扱いは X の規約・ポリシーに従います。
  • 外部サイトへのリンク: おすすめサウナの公式サイトなど、本サイト外のページへのリンクがあります。リンク先での情報の取り扱いについて、本サイトは責任を負いません。

5. 免責事項

  • 診断結果は、質問への回答をもとにした娯楽目的のものです。医学的・科学的な根拠に基づく判定や、健康上の助言ではありません。
  • サウナの利用は、体調に合わせて無理のない範囲で行ってください。体調不良・飲酒後・食後すぐ・持病のある方などは、利用前に医師や施設の案内に従ってください。水分補給も忘れずに行ってください。
  • 「おすすめのサウナ」に掲載している施設の情報は、掲載時点のものです。営業時間・料金・設備・利用条件などは変更されることがあります。ご利用前に、必ず施設の公式サイトなどで最新の情報をご確認ください。特定の施設を保証・推奨するものではありません。
  • 本サイトの利用により生じたいかなる損害についても、運営者は責任を負いません。また、予告なく内容の変更・公開の停止を行うことがあります。

ご意見・不具合のご連絡・本ポリシーに関するご質問は、GitHub の Issues からお願いします（GitHub アカウントが必要です）。Issue は誰でも閲覧できる形で公開されるため、氏名・メールアドレスなどの個人情報は書き込まないでください。
